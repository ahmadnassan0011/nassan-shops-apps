# تطبيقات جرد المواد — نسخة الموبايل القابلة للتثبيت

هاد المجلد نسخة قابلة للنشر على الإنترنت (GitHub Pages) من صفحات:
- `سوبر ماركت.html` → `supermarket/`
- `ألبان وأجبان.html` → `dairy/`
- `قرطاسية.html` → `stationery/`
- `تطبيق جرد-المواد/لوحة_المالك.html` → `admin/`

كل صفحة صارت PWA (تطبيق ويب قابل للتثبيت): عندها `manifest.json` + أيقونة
+ `sw.js` (service worker للعمل دون إنترنت وفتح سريع). لما تفتح الرابط
على موبايل وتضغط "تثبيت التطبيق" / "إضافة إلى الشاشة الرئيسية"، بتصير
أيقونة عالشاشة الرئيسية تفتح بملء الشاشة زي أي تطبيق عادي.

## كيف تحدّث المحتوى لاحقاً

الملفات الأصلية (المصدر الوحيد للحقيقة) هيه بالمجلد الأب:
`سوبر ماركت.html`, `ألبان وأجبان.html`, `قرطاسية.html`,
و`تطبيق جرد-المواد/لوحة_المالك.html` (نسخة الأدمن).

كل ما تعدّل وحدة منهم:
1. انسخها فوق نسخة `index.html` المقابلة هون (مثلاً:
   `cp "../سوبر ماركت.html" "supermarket/index.html"`).
2. إذا التعديل مهم (مو تفصيل بسيط)، بدّل رقم `CACHE` بأول
   `sw.js` المقابل (مثلاً `supermarket-v1` → `supermarket-v2`) —
   هيك أجهزة الموظفين بتاخد النسخة الجديدة فوراً بدل ما تضل عالقديمة
   بالـ cache.
3. `git add -A && git commit -m "..." && git push` — GitHub Pages
   بيحدّث نفسه تلقائياً خلال دقيقة أو اثنين.

## نظام موافقة الأجهزة (الموظفين)

أي جهاز موظف بيفعّل المزامنة أول مرة بيصير بحالة "بانتظار الموافقة"
تلقائياً بتبويب "Shops" بشيت غوغل، وبيوصل إيميل تلقائي لنفس حساب
غوغل يلي منشور عليه Code.gs. لازم تفتح تطبيق الأدمن (`admin/`) ←
"📱 الأجهزة" وتضغط قبول (✓) أو رفض (✕). إذا الجهاز غيّر اسم المتجر
لاحقاً من الإعدادات، بيرجع "بانتظار الموافقة" تلقائياً لحد ما توافق
على الاسم الجديد.

## نظام موافقة أجهزة الأدمن

نفس الفكرة، بس للوحة الأدمن نفسها: أول جهاز أدمن يفتح الإعدادات
(غالباً سطح المكتب) بيصير معتمد تلقائياً — "الجهاز الرئيسي" ⭐
(نقطة الثقة الأولى، محمي: محدا يقدر يرفضه أو يحذفه، ولا حتى جهاز
أدمن معتمد تاني). أي جهاز أدمن بعده (موبايل مثلاً) لازم جهاز
معتمد يوافق عليه من قسم "🔐 أجهزة الأدمن" قبل ما يقدر يشوف بيانات
المحلات. فيك تحذف أي جهاز (موظف أو أدمن) نهائياً من اللائحة بزر
🗑 لو صار زايد عن الحاجة (تجربة، جهاز قديم، الخ).

## المحلات النشطة

شريط فوق جدول المواد (بالأدمن، سطح المكتب والموبايل) بيعرض كل
محل بنقطة لونها بتعتمد على آخر نشاط: 🟢 نشط الآن (خلال ١٠ دقائق)،
🟡 نشط اليوم، ⚪ غير نشط، 🟠 بانتظار الموافقة. تطبيق الموظف بيبعث
"نبضة حياة" كل دقيقة لحد ما يضل مفتوح.

## حذف مواد محل (سطح المكتب فقط)

من تطبيق الأدمن على سطح المكتب، زر "🗑 حذف محل" (مخفي على نسخة
الموبايل عمداً) بيفوّتك على سجل مواد المحل المحدد، وبتختار الكل
أو بعض المواد بس (تحديد بصناديق) وبعد رسالة تأكيد صريحة بتنحذف
نهائياً من غوغل شيت وصور Drive المرتبطة فيها. لو حذفت آخر مادة
لمحل، بينمسح تسجيله من "الأجهزة المتصلة" تلقائياً كمان. تطبيق
الموظف بيكتشف الحذف تلقائياً (خلال دقيقة) ويمسح المواد من نسخته
المحلية هو كمان.

## نسخة احتياطية بلا إنترنت (تطبيق الأدمن على الموبايل)

تطبيق الأدمن المستضاف عالإنترنت (`admin/`) بيحفظ آخر نسخة من
المواد + الصور بمتصفح الموبايل نفسه (IndexedDB) تلقائياً بعد كل
تحديث ناجح. إذا انقطع النت، بيعرض آخر نسخة محفوظة بدل شاشة فاضية.
أول فتحة بعد أي تحديث كبير للكتالوج محتاجة نت لحتى يخلص تحميل
الصور بالخلفية.

## فتح سريع (سطح المكتب والموبايل)

الأدمن هلق بيعرض آخر نسخة محفوظة محلياً فوراً عند الفتح (بدون ما
يستنى الشبكة)، وبنفس الوقت بيبلش تحديث حقيقي من غوغل شيت بالخلفية
— فبيصير الفتح سريع دايماً حتى لو النت بطيء. كمان قللنا الكتابة
غير الضرورية لشيت "AdminDevices" مع كل تحديث (كانت بتبطّئ كل
طلب)، فصار فحص حالة الجهاز أخف بكثير.

هاي الميزات كلها موجودة بالباكند (`Code.gs`) — لازم تكون ناشر آخر
نسخة منه (Deploy ← Manage deployments ← تعديل ← Version: New
version) حتى تشتغل.
