# تطبيقات جرد المواد — نسخة الموبايل القابلة للتثبيت

هاد المجلد نسخة قابلة للنشر على الإنترنت (GitHub Pages) من صفحات:
- `سوبر ماركت.html` → `supermarket/`
- `ألبان وأجبان.html` → `dairy/`
- `قرطاسية.html` → `stationery/`

كل صفحة صارت PWA (تطبيق ويب قابل للتثبيت): عندها `manifest.json` + أيقونة
+ `sw.js` (service worker للعمل دون إنترنت وفتح سريع). لما تفتح الرابط
على موبايل وتضغط "تثبيت التطبيق" / "إضافة إلى الشاشة الرئيسية"، بتصير
أيقونة عالشاشة الرئيسية تفتح بملء الشاشة زي أي تطبيق عادي.

## كيف تحدّث المحتوى لاحقاً

الملفات الأصلية (المصدر الوحيد للحقيقة) هيه بالمجلد الأب:
`سوبر ماركت.html`, `ألبان وأجبان.html`, `قرطاسية.html`.

كل ما تعدّل وحدة منهم:
1. انسخها فوق نسخة `index.html` المقابلة هون (مثلاً:
   `cp "../سوبر ماركت.html" "supermarket/index.html"`).
2. إذا التعديل مهم (مو تفصيل بسيط)، بدّل رقم `CACHE` بأول
   `sw.js` المقابل (مثلاً `supermarket-v1` → `supermarket-v2`) —
   هيك أجهزة الموظفين بتاخد النسخة الجديدة فوراً بدل ما تضل عالقديمة
   بالـ cache.
3. `git add -A && git commit -m "..." && git push` — GitHub Pages
   بيحدّث نفسه تلقائياً خلال دقيقة أو اثنين.

## ملاحظة

المحلية اللي بتشتغل عبر PowerShell) — هاد فقط للنشر على الإنترنت
عشان يصير قابل للتثبيت عالموبايل.
